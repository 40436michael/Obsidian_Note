# 童子軍規則

**定義**：每次碰到程式碼，都讓它比原本乾淨一點（[[Clean Code 01 無瑕的程式碼]]）。

## 各來源怎麼說

### Clean Code 第 1 章

> 童子軍原則:每一次都讓程式碼比以前乾淨一點

（重點，[[Clean Code 01 無瑕的程式碼]]）

> 改bug 時順手改一些難以閱讀的變數名稱

（可以怎麼應用，[[Clean Code 01 無瑕的程式碼]]）

> 簽入的程式碼要比簽出時更乾淨

（書中引文，[[Clean Code 01 無瑕的程式碼]]）
