# 童子軍規則

**定義**：每次碰到程式碼，都讓它比原本乾淨一點（[[Clean Code 01 無瑕的程式碼]]）。

> 簽入的程式碼要比簽出時更乾淨。

## 為什麼有用

- **讓整理變成習慣**：不需要專門排時間做大規模重構，整理會分散在每一次修改裡（[[Clean Code 01 無瑕的程式碼]]）。
- **對抗[[技術債]]**：每次都還一點，債就不會越滾越大。

## 我的應用

- 改 bug 時，順手把難以閱讀的變數名稱改掉（[[Clean Code 01 無瑕的程式碼]]）。
