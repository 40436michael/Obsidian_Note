# 技術債

**定義**：為了省時間寫出的爛程式碼，之後讓開發變慢的代價（[[Clean Code 01 無瑕的程式碼]]）。

## 各來源怎麼說

### Clean Code 第 1 章

> 今天為了省下開發時間寫出來的爛程式碼未來會像迴旋鏢一樣打你頭上。

（一句話總結，[[Clean Code 01 無瑕的程式碼]]）

> 邊寫程式邊整理程式碼

（重點，[[Clean Code 01 無瑕的程式碼]]）

> 走的快的唯一方法，就是把事情做好

（書中引文，[[Clean Code 01 無瑕的程式碼]]）

## 相關

- [[童子軍規則]]：每次碰到程式碼就清理一點，爛程式碼才不會累積成技術債
- [[先讓它能動再讓它正確]]：只做到「能動」、跳過「再讓它正確」，就會留下技術債
