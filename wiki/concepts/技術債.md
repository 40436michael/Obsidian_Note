# 技術債

**定義**：為了省時間寫出的爛程式碼，當下看似加快了進度，之後會讓開發越來越慢（[[Clean Code 01 無瑕的程式碼]]）。

## 各來源的說法

### Clean Code
- **我的說法**：今天省下的開發時間，未來會像迴旋鏢一樣打回自己頭上（[[Clean Code 01 無瑕的程式碼]]）。
- **作者的主張**：走得快的唯一方法，就是把事情做好（[[Clean Code 01 無瑕的程式碼]]）。

## 怎麼避免

- **邊寫邊整理**，不要累積到之後才處理（[[Clean Code 01 無瑕的程式碼]]）。
- 遵守[[童子軍規則]]。
