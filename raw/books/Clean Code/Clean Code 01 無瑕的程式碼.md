# Clean Code 01 無瑕的程式碼

## 一句話總結
<!-- 用自己的話，不要抄書 -->
今天為了省下開發時間寫出來的爛程式碼未來會像迴旋鏢一樣打你頭上。
## 重點
- 邊寫程式邊整理程式碼
- 不用追求完美的程式碼，而是讓程式碼舒適
- 即使多年後別人閱讀也能輕鬆理解
- 童子軍原則:每一次都讓程式碼比以前乾淨一點
- 

## 引文
> 走的快的唯一方法，就是把事情做好
> 先讓程式碼能運作再讓它正確
> 簽入的程式碼要比簽出時更乾淨
