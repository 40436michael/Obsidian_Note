# Clean Code 02 清理你的程式碼

## 一句話總結
<!-- 用自己的話，不要抄書 -->
先讓程式碼能動，再逐步清理程式碼

## 重點
- 先寫出一份能執行的程式碼
- 再將類似的程式碼提取成函式
- 建立內部物件避免把引數傳來傳去給輔助函式
- 

## 引文
> 先讓它能運作，再讓它正確--或只至少更好
> 如果你覺得某件事很聰明、很複雜，小心-它很可能只是自我放縱(太聰明反而不自然)

## 例子
<!-- 技術書：Before / After 程式碼 -->
將所有檢查寫成2個function : 檢查不合法的相鄰前綴組合和檢查字元重複次數過多的錯誤
49NGO這種字元替換太聰明的寫法反而不自然，感覺別人要花許久才會讀懂
